# Naming Conventions

## Purpose

Ensure consistent naming across code, prompts, workflows, assets and
projects.

## Python

-   snake_case for files/functions
-   PascalCase for classes
-   UPPER_CASE for constants

## Markdown

Use descriptive names: - ResearchAgent.md - DocumentaryWorkflow.md -
Beyond3Baje.md

## Projects

YYYY-MM-DD_Channel_ShortTitle

Example: 2026-07-21_Beyond3Baje_BhangarhFort

## Assets

asset_type_subject_version.ext
