# Vision

## Product

Spilled Coffee AI Studio

## Organization

Buzzcaf Private Limited

## Business Division

Buzzcaf Media

## Purpose

Spilled Coffee AI Studio is the internal AI operating system used by
Buzzcaf Media to research, write, produce, edit, publish and improve
media across all brands.

## Supported Brands

-   Beyond3Baje
-   Khayal3Baje
-   Spilled Coffee Studio
-   Spilled Coffee After Dark
-   Life3Baje

## Long-term Goals

-   One knowledge base
-   One project system
-   One workflow engine
-   AI-first media production
-   Support books, films, VR and games in future

## Core Principle

The system is workflow-driven. Agents are reusable workers inside
workflows.
