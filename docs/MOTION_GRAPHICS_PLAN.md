# Motion graphics plan (2026-10-27)

Creator ask: "more motion graphics in BuzzEdit for the explainer and other such
videos, more effects the agents use automatically, the best and most happening
in the market." Order agreed: **Phase 1, then Phase 3, then Phase 2.**

## Why

Every BuzzEdit graphic today (maps, charts, cards, timeline, documents) is a
PIL still given a Ken Burns push or a pop-in. Nothing *inside* a graphic moves.
This plan adds a motion-template engine on **Remotion** (React -> frames ->
video, headless Chromium; free licence for individuals / companies of up to 3
people, checked 2026-10-27 in remotion LICENSE.md). Each effect is one
composition; Python builds its props from a plan beat, Node renders it, the
result is a normal `Asset(kind="video", source="motion")` placed like any
cutaway. A render that fails falls back to the existing PIL still, so motion
can never break a video.

## Architecture (fixed by M1; later items build on it)

**`BuzzEdit/motion/`** -- a self-contained Node project (not the Electron
app's `node_modules`).
- `package.json` with exact versions; every `@remotion/*` at the same version.
- `src/index.ts` -> `registerRoot`; `src/Root.tsx` registers every entry of
  `src/registry.ts` (`export const COMPOSITIONS = [...]`, one line per
  composition) with `calculateMetadata` taking `width`, `height`, `fps` and
  `durationInFrames` from props.
- `src/theme.ts`: the `Theme` type every composition takes as `props.theme`:
  `{bg, panel, fg, muted, accent, accent2, water, land, border, fontHead,
  fontBody, paper, grain, noir}`. Fonts are files in `public/fonts/`
  (incl. Noto Sans Devanagari for Hindi), loaded with `staticFile`.
- `render.mjs jobs.json results.json`: bundles once (bundle cached in
  `motion/.bundle/`, keyed by a hash of `src/` + `package-lock.json`),
  `ensureBrowser()`, then each job: `selectComposition` + `renderMedia`.
  Opaque -> H.264 MP4 (yuv420p, crf 18). Transparent -> ProRes 4444 MOV
  (`yuva444p10le`). One result line per job `{id, ok, out, error, seconds}`.
  `--selftest` renders 1 s of every registered composition at 320x180.
- Job: `{id, composition, props, width, height, fps, frames, out,
  transparent, concurrency}`.

**`BuzzEdit/backend/presentation/motion.py`** -- the Python side.
- `available()` (node + `motion/node_modules` + browser + cached self-test).
- `theme_for(genre, art_style)` from `art_style.card_style`, `maps.STYLES`
  and the chart style (noir for horror/true crime).
- `BUILDERS: Dict[str, Callable[[Beat, ctx], Optional[job]]]` -- one entry per
  motion kind; later items add one line each, their builders live in their own
  modules (`motion_data.py`, `motion_transitions.py`, ...).
- `render_motion_assets(beats, project_dir, width, height, genre, settings)
  -> (assets, failures, handled_beat_ids)`: cache key = sha of (composition,
  props, theme, size, fps, frames, engine version); files under
  `assets/motion/`. Node runs as one subprocess per batch, BELOW_NORMAL
  priority, no window, `motion_concurrency` (default 4) -- the PC must not
  lag; `master_control.wait_if_paused` before each batch.
- Wired into `director._draw_local_assets` **before** the PIL renderers; beats
  it handled are skipped by them; a failed beat stays for PIL.
- `PresentationSettings.motion_graphics: bool = True`.

**Duration.** A motion asset is rendered at the beat's planned length
(`planned_duration_s`, else `end_s - start_s`, clamped 2.5-12 s). Animations
land their key information by ~40% of the length and keep a slow live drift to
the end. Placement treats `source == "motion"` as a graphic: no 5 s clip
minimum, no Ken Burns/zoom, native speed; a longer window holds the last frame.

**Studio side.** Each new kind is a row in `integrations/effect_catalog.py`
(fields, example, aliases, normalize, directive), carried by
`buzzedit_script.py`, pinned by tests against the strings BuzzEdit's
`script.py` parses, and given genre / art-style favourites. Story channels
(pictures only) get only the picture-like kinds: maps, charts, timeline,
parallax, stick animation, collage on a mix. Text-like kinds (kinetic, flow,
icons, UI, callouts) only where the short text cards are allowed
(`art_style` text flag), and transitions never on a story channel.

## Items

### Phase 1
- **M1 Engine + kinetic text.** `motion/` project, `render.mjs`,
  `motion.py`, placement/director/settings wiring, `KineticText`
  composition (new kind `kinetic_text`, directive `[kinetic: text with *marks*
  | style=slam|stack|reveal|typewriter]`: words spring in, marked words in the
  accent with a punch and an underline sweep, theme background with a slow
  gradient/grain, paper texture when `theme.paper`), BuzzEdit `script.py`
  grammar + `BeatKind`, selftest in `installer/selftest.py` and `npm install`
  (never `npm ci`; check `npm ls` first) in `installer/setup_env.ps1`.
- **M2 Animated map + charts.** `MotionMap` (orthographic globe turns to the
  place and zooms in, highlighted country/state fills, pin drops with a pulse
  ring, label slides in; with a route, a dashed line draws between places in
  order with a travelling dot; clean and noir looks). The in-view Natural Earth
  features come from Python (`maps.geocode`, features clipped to the view,
  coordinates rounded), the world outline from the `world-atlas` 110m file in
  `public/`. `MotionChart` (bars grow staggered with counting values; line
  draws with `evolvePath`, points pop; pie/donut slices sweep), `MotionStat`
  (big number counting up + label, for `stat_callout`), `MotionTimeline`
  (ruler draws, marker slides to the active date, big figure counts in).
  Same directives as today -- nothing changes for the planner.
- **M3 Shape transitions.** Transparent stingers `shape_wipe`, `iris`,
  `ink`, `bars`, `paper_tear` (0.8 s, theme colours), rendered once per
  theme + size and reused, placed on the top track centred on the cut. The
  compiler must composite a ProRes 4444 overlay with its alpha (verified by a
  test render). Added to BuzzEdit's fx palette / `[fx: ...]` grammar.
- **M4 Studio catalog, Phase 1.** `kinetic_text` row, the new transitions in
  `TRANSITIONS`, favourites (explainer, mixed, mixed_quirky, education,
  finance, documentary), story-channel gating, tests.

### Phase 3
- **M5 Paper-cutout collage.** `PaperCollage` (kind `paper_collage`,
  directive `[collage: prompt A ; prompt B ; ... | caption=...]`): 2-4
  generated stills cut out (an existing matte/background-removal model in
  BuzzEdit if any; fallback: polaroid/rounded photo with a white border),
  white outline + drop shadow, on paper texture, stepping in "on twos" with
  stop-motion jitter, doodled arrows and sticker labels.
- **M6 2.5D parallax.** Depth map per still (Depth Anything V2 *Small*,
  Apache-2.0, in the BuzzEdit venv or ComfyUI), `Parallax` composition
  (`@remotion/three` displaced plane, small camera dolly, `gl: angle`), used on
  a share of stills with real depth (`parallax_share`, default 0.3), every
  channel including story channels; placed as a still, not as a clip.
- **M7 Animated stick figures.** `StickScene`: an SVG rig (head, 2-segment
  limbs) with poses idle, walk, run, point, shrug, think, cheer, fall, sit,
  scared, swim, climb; simple SVG props (ship, wave, house, tree, phone, money,
  ...); boiling hand-drawn lines; whiteboard or paper ground. Directive
  `[stick: action=swim | scene=... | prop=ship | caption=...]`. A share of
  stick-figure shots in `stick_figure` / `mixed` / `mixed_quirky` become these.
- **M8 Studio catalog, Phase 3.** Rows, art-style favourites, mix shares, tests.

### Phase 2
- **M9 Flow diagram + icon list.** `FlowDiagram` (`[flow: a ; b ; c |
  layout=chain|cycle|branch]`, boxes and arrows draw in order) and
  `IconList` (`[icons: label ; label | mode=list|pros_cons]`, bundled Lucide
  icons picked by keyword, staggered pops, tick/cross mode).
- **M10 UI mockups + callouts.** `UiMockup` (generic post / forum / chat /
  search / headline -- no real logos; the planner may quote only a real
  sourced post, never invent one for a real person) and `Callout` on a
  generated still (circle, arrow or magnifier on a 3x3 grid region).
- **M11 Motion Gallery.** BuzzEdit `POST /api/motion/gallery` renders every
  composition with sample props into
  `B:\youtubeProjects\Buzzcaf_Media\Samples\motion_gallery\<date>\` with an
  `index.html`; a Studio button opens it.
- **M12 Studio catalog, Phase 2.** Rows, favourites, gating, tests.
