# Sound Design Plan: Peeche Mat Khodna — The Forbidden Boundary

## 1. Global Audio Aesthetic
- **Primary Texture:** Dark Ambient / Rural-Folk Drone (Tanpura, Sarangi, Shehnai base) — never synth-horror, never jump-scare stings.
- **Core Rule (Silence Rule):** Every time a "Rule" is read, an entity is named (Pishach/Pret/Masaan), or a chilling line lands, drop to **0% volume (off)** for 1.5–3s before resuming.
- **Tempo Bands:** 60-75 bpm (folklore/scene-setting) → 85-100 bpm (investigation build) → dramatic hit (reveal, no jump-scare stinger — use sub-bass swell + taiko instead).

## 4. Transition & Structural Notes
- **Sc.10 → Sc.11:** Hard cut to black + 3s silence, then drone re-enters *cleaner/warmer* — audibly signals "we've left the story."
- **Per-Rule Silence Rule (Sc.06):** Non-negotiable per brand style guide — every rule gets its own audio "breath": read → pluck sting → near-silence (1.5–2s) → next rule.
- **Entity-naming Silence Rule (Sc.13):** Apply identical silence treatment to "Pishach," "Pret," and "Masaan" on first utterance only.
- **No jump-scare stingers anywhere** — all tension built via drone pitch/density shifts and strategic silence, per brand mandate.
- **Bookend symmetry:** Sc.01 cold-open silence and Sc.18 closing silence should use the same audio signature (low string note → off) to close the narrative loop.
