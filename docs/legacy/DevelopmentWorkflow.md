# Development Workflow

1.  Design Markdown specification.
2.  Review architecture.
3.  Implement Python.
4.  Write tests.
5.  Validate.
6.  Merge.

## Versioning

Major.Minor.Patch

Phase 1 starts at v0.1.0

## Definition of Done

-   Markdown complete
-   Python implemented
-   Tests passing
-   Example execution documented
