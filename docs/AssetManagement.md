# Asset Management

## Purpose

Manage every reusable media asset across Buzzcaf Media.

## Asset Types

-   Stock video
-   AI images
-   Thumbnails
-   Sound effects
-   Music
-   Fonts
-   Logos
-   Icons
-   Motion graphics
-   Video templates
-   LUTs
-   B-roll
-   Animation files

## Metadata

-   Unique ID
-   Title
-   Tags
-   Source
-   License
-   Creation date
-   Used in projects
-   Status

## Rules

Never duplicate assets unnecessarily. Track every usage across projects.
